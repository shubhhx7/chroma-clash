# Audio Licensing

Every audio file under `assets_processed/audio/` is **generated in-repo** by
`tools/generate-combat-audio.ts` (deterministic DSP synthesis: filtered-noise
whooshes, inharmonic metal partials for blocks/parries, pitched-thump +
noise-crack impacts, formant-filtered non-verbal vocal grunts). No third-party
recordings, no downloaded samples, no copyrighted material, no TTS.

- **Owner:** the Chroma Clash project (works generated by project tooling).
- **License:** same as the repository; regenerate at any time with
  `npm run assets:audio`.
- The procedural music beds are synthesized live at runtime by
  `src/game/audio/AudioManager.ts` (oscillator pads + sub pulse) — also
  original, no external material.

When commissioned/recorded audio replaces any of these files, list each new
file here with its source and license before shipping.
